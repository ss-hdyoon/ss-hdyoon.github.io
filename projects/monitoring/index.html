모니터링 및 알림 개선

CloudWatch CPU 알람과 SNS 알림 주제를 Terraform으로 선언하는 최소 예제입니다.

CloudWatch · SNS · Terraform교육용 샘플 · 실제 수행 사례 아님

프로젝트 구성

이 폴더는 독립 실행/실습이 가능한 예제 파일로 구성했습니다. 정확한 실행 조건과 보안 주의사항은 해당 폴더의 README.md를 확인하세요.

  • main.tf — Terraform
  • variables.tf — variables
  • outputs.tf — outputs

로컬 검증 예시

terraform init
terraform validate
terraform plan -var="instance_id=i-xxxxxxxxxxxxxxxxx" -var="notification_email=you@example.com"

실습용 실제 EC2 인스턴스 ID와 알림 이메일이 필요합니다. SNS 이메일 구독 확인이 필요하며, terraform apply 시 AWS 리소스가 생성되어 과금될 수 있습니다.
