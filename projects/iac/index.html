IaC 기반 인프라 구성

VPC와 Public Subnet, Internet Gateway 및 라우팅을 Terraform으로 관리하는 실습 예제입니다.

Terraform · VPC · AWS교육용 샘플 · 실제 수행 사례 아님

프로젝트 구성

이 폴더는 독립 실행/실습이 가능한 예제 파일로 구성했습니다. 정확한 실행 조건과 보안 주의사항은 해당 폴더의 README.md를 확인하세요.

  • main.tf — Terraform
  • variables.tf — variables
  • outputs.tf — outputs

로컬 검증 예시

terraform init
terraform validate
terraform plan
← 프로젝트 목록README 원문 보기 ↗

실행 전 확인

terraform apply를 실행하면 VPC 관련 AWS 리소스가 생성됩니다. VPC·Subnet 등 자체 비용은 없을 수 있으나 연결 리소스/향후 변경에 따라 과금될 수 있습니다. 실습 후 terraform destroy 하세요.
