CI/CD 파이프라인 표준화

GitHub Actions를 이용한 정적 사이트의 테스트·검증·GitHub Pages 배포 예제입니다.

GitHub Actions · Python · GitHub Pages교육용 샘플 · 실제 수행 사례 아님

프로젝트 구성

이 폴더는 독립 실행/실습이 가능한 예제 파일로 구성했습니다. 정확한 실행 조건과 보안 주의사항은 해당 폴더의 README.md를 확인하세요.

  • .github/workflows/pages.yml — workflow
  • scripts/check_site.py — smoke test
  • site/index.html — demo site

로컬 검증 예시

python3 scripts/check_site.py

실행 전 확인

워크플로는 이 예제 프로젝트를 별도의 GitHub 저장소 루트에 옮긴 후 실행하는 구조입니다. Pages 배포 전 저장소 Settings → Pages → Source를 GitHub Actions로 설정하세요.
